\task{%
Подготовить обучающий корпус на основе трёх открытых датасетов
(DEAM, Harmonix~Set, GTZAN) с унифицированным пайплайном

Собран корпус 3\,545 композиций; реализован модуль

\task{%
Разработать и реализовать пять архитектур мульти-задачных
моделей~--- CNN, CNN\,+\,BiLSTM, PANNs\,+\,Linear,
PANNs\,+\,BiLSTM, AST~--- для оценки вклада temporal modeling,
pretraining и трансформерной парадигмы.%
\result{%
Реализована CNN с SE-блоками ($\approx$\,800\,тыс. параметров),
надстройки BiLSTM, линейный классификатор над PANNs и частично
размороженный AST (14{,}4\,млн trainable из 87\,млн).%
}}

\task{%
Выполнить экспериментальное сравнение пяти архитектур по четырём
задачам на едином тестовом корпусе.%
\result{%
Четыре последовательных эксперимента (v1, v2, AST~v2,
negative-result CNN~v3). Лучшая конфигурация~--- AST~v2:
среднее accuracy 58{,}5\,\%, сегмент 40{,}6\,\%
(+5{,}3\,п.п. к CNN), жанры 81{,}5\,\%.%
}}

\task{%
Реализовать пост-обработку сегментных предсказаний на базе
декодера Витерби с музыкологическими априори.%
\result{%
Декодер v2 с temperature scaling, матрицей переходов, позиционными
приорами и per-class min-duration повышает Boundary~F1 на
14\,пунктов относительно argmax.%
}}

\task{%
Разработать веб-прототип для интерактивной демонстрации
результатов.%
\result{%
Трёхзвенная система React\,19\,+\,Vite / Elysia~(Bun) / FastAPI,
дашборд из шести синхронизированных панелей, Vibe~Mode
(WebGL2-шейдер), ID3/YouTube-метаданные.%
}}

\task{%
Сформулировать ограничения подхода и направления дальнейшей
работы.%
\result{%
Ограничения: OOD на современной музыке, потолок per-window

\begin{englishabstract}
This master's thesis presents a software module for automatic
multi-task analysis of musical recordings. For an input track the
system produces a temporal timeline of structural segments (Intro,
Verse, Chorus, Bridge, Instrumental, Outro), arousal/valence
curves (Russell circumplex) and a top-3 genre prediction.

Five architectural configurations are developed and compared: a
CNN per-window with Squeeze-and-Excitation attention, CNN\,+\,BiLSTM,
a linear classifier and a BiLSTM over frozen PANNs embeddings, and
a partially fine-tuned Audio Spectrogram Transformer (AST)
pretrained on AudioSet. All are trained jointly on DEAM, Harmonix
Set and GTZAN by a round-robin multi-task scheduler with focal
loss and SpecAugment. Four sequential experiments (v1, v2, AST~v2
extension and a negative-result CNN~v3) yield AST~v2 as the best
overall configuration with average accuracy 58.5\,\% and a
5.3-point gain on structural segmentation over the strongest
CNN baseline. A post-processing pipeline based on Viterbi
decoding with a musicological transition matrix, position priors
and per-class minimum durations raises the boundary~F1 of the
structural segmentation by 14~points over the raw argmax
baseline.

The work also delivers an interactive web prototype with a
synchronised six-panel dashboard and a fullscreen Vibe~Mode WebGL2
visualizer reactive to the audio spectrum.

\end{englishabstract}

\subsection*{Актуальность работы}
\addcontentsline{toc}{subsection}{Актуальность работы}

Современные музыкальные приложения — стриминговые сервисы, ритм-игры, инструменты для DJ-микширования, образовательные платформы, рекомендательные системы — всё чаще требуют \textbf{семантического понимания аудио}, а не просто его воспроизведения. Пользователю или алгоритму необходимо знать: где в треке начинается припев, насколько музыка эмоциональна, к какому жанру относится фрагмент, какова его структурная разметка во времени.

Решение этих задач вручную невозможно при объёмах современных каталогов: только Spotify содержит более 100 миллионов треков. Автоматизация анализа музыки через методы машинного обучения — единственный путь масштабирования. Развитие глубоких нейронных сетей за последние годы сделало возможным качественный прорыв в этой области, однако \textbf{существующие решения остаются фрагментированными}: каждая задача (структурный анализ, распознавание эмоций, классификация жанров) обычно решается отдельной специализированной моделью. Это приводит к избыточным вычислениям, несогласованности результатов и сложности интеграции.

Настоящая работа исследует возможность \textbf{унификации} четырёх ключевых задач музыкального анализа в рамках одной мульти-задачной модели глубокого обучения с интерактивной демонстрацией результатов через веб-прототип.

\subsection*{Цель и задачи работы}
\addcontentsline{toc}{subsection}{Цель и задачи работы}

\textbf{Цель}: разработать прототип системы автоматического многоаспектного анализа музыкальных композиций на основе мульти-задачной модели глубокого обучения, формирующей по входному аудиотреку структурную, эмоциональную и жанровую разметку во времени.

Для достижения цели поставлены следующие задачи:

\begin{enumerate}
  \item Провести обзор современного состояния области Music Information Retrieval, выявить характерные подходы и ограничения существующих решений.
  \item Подготовить обучающий корпус из трёх открытых датасетов (DEAM, Harmonix Set, GTZAN) с унифицированным пайплайном предобработки.
  \item Разработать и реализовать пять архитектур мульти-задачных моделей, охватывающих ключевые подходы (CNN, BiLSTM, PANNs, Audio Spectrogram Transformer).
  \item Провести экспериментальное сравнение архитектур и выявить наилучшую конфигурацию.
  \item Реализовать пост-обработку предсказаний модели с учётом музыкальных априори (Viterbi-декодирование, position priors, slim-duration merge).
  \item Разработать веб-прототип с синхронизированным дашбордом из шести аналитических панелей для интерактивной демонстрации возможностей системы.
  \item Идентифицировать ограничения подхода и сформулировать направления дальнейшей работы.
\end{enumerate}

\subsection*{Объект и предмет исследования}
\addcontentsline{toc}{subsection}{Объект и предмет исследования}

\textbf{Объект исследования} — методы автоматического анализа цифровых аудиозаписей музыки на основе глубокого обучения.

\textbf{Предмет исследования} — мульти-задачные нейросетевые архитектуры и пост-обработка их предсказаний для задач структурной сегментации, распознавания эмоций (arousal/valence) и классификации жанров.

\subsection*{Научная новизна}
\addcontentsline{toc}{subsection}{Научная новизна}

Научная новизна работы заключается в следующем:

\begin{enumerate}
  \item Проведено систематическое сравнение пяти архитектур мульти-задачных моделей (CNN, CNN+BiLSTM, PANNs+Linear, PANNs+BiLSTM, AST) на едином корпусе DEAM+Harmonix+GTZAN, отвечающее на пять исследовательских вопросов о вкладе различных факторов (temporal modeling, pretraining, transformer architecture).

  \item Предложен и количественно оценен композитный pipeline пост-обработки сегментных предсказаний, объединяющий Viterbi-декодирование с musicological position priors и итеративное слияние коротких сегментов. Pipeline даёт прирост Boundary F1 на 14 пунктов относительно сырых argmax-предсказаний.

  \item Разработан и документирован паттерн «академически честного UX» для классификационных моделей с ограниченным набором категорий обучающего датасета — отображение top-3 предсказаний с предупреждением о низкой уверенности при out-of-distribution входных данных.

  \item Документирован negative result эксперимента CNN v3 (failed retrain с агрессивной перебалансировкой class weights) — академически ценный отрицательный результат, редко публикуемый в литературе.
\end{enumerate}

\subsection*{Практическая значимость}
\addcontentsline{toc}{subsection}{Практическая значимость}

Практическая значимость работы:

\begin{enumerate}
  \item \textbf{Open-source прототип системы}, доступный для исследовательских и образовательных целей: полный исходный код, обученные модели, документация эксперимента.

  \item \textbf{Воспроизводимый pipeline} обучения и оценки: все эксперименты воспроизводимы по предоставленным конфигурационным файлам.

  \item \textbf{Демонстрационная система}, пригодная для презентации возможностей deep learning в анализе музыки конечным пользователям — музыкантам, исследователям, разработчикам музыкальных приложений.

  \item \textbf{Базовая платформа} для дальнейших исследований: расширение на real-time inference, mobile deployment, дообучение на современных датасетах — естественные следующие шаги на основе предоставленной инфраструктуры.
\end{enumerate}

\subsection*{Структура работы}
\addcontentsline{toc}{subsection}{Структура работы}

Работа состоит из введения, семи глав, заключения, списка использованных источников и шести приложений.

\begin{itemize}
  \item \textbf{Глава 1} содержит обзор предметной области MIR, анализ существующих подходов к решаемым задачам и обоснование выбора архитектурных направлений настоящей работы.
  \item \textbf{Глава 2} формулирует постановку задачи, исследовательские вопросы и обоснование мульти-задачного подхода.
  \item \textbf{Глава 3} описывает используемые датасеты, схему предобработки признаков и стратегию разбиения на train/val/test.
  \item \textbf{Глава 4} представляет архитектурные решения: пять конфигураций моделей, multi-task функцию потерь, post-processing pipeline.
  \item \textbf{Глава 5} содержит экспериментальную часть: четыре эксперимента (v1, v2, AST v2, CNN v3), сводное сравнение всех конфигураций, ablation post-processing.
  \item \textbf{Глава 6} описывает реализованный веб-прототип: трёхзвенную архитектуру, синхронизированный дашборд, ключевые UX-решения.
  \item \textbf{Глава 7} обобщает результаты, идентифицирует ограничения и сравнивает с современным state-of-the-art.
\end{itemize}

В заключении формулируются основные результаты работы и направления дальнейших исследований. Приложения содержат описание датасетов, гиперпараметры экспериментов, confusion matrices, скриншоты прототипа, JSON-схему timeline и CLI-команды для воспроизведения.

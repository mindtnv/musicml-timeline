\subsection*{Основные результаты работы}
\addcontentsline{toc}{subsection}{Основные результаты работы}

В рамках настоящей научно-исследовательской работы решены все поставленные задачи и достигнута основная цель — разработан и реализован прототип системы автоматического многоаспектного анализа музыкальных композиций.

\textbf{Конкретные результаты:}

\begin{enumerate}
  \item \textbf{Реализованы и обучены пять архитектурных конфигураций} мульти-задачных моделей: CNN с SE-блоками, CNN+BiLSTM, PANNs+Linear, PANNs+BiLSTM, Audio Spectrogram Transformer (fine-tuned). Все модели сравнены на едином тестовом корпусе по четырём задачам.

  \item \textbf{Проведено четыре экспериментальных запуска} (v1 baseline, v2 улучшенный, AST v2, CNN v3 как negative result) с детальной документацией изменений гиперпараметров и анализом per-class результатов.

  \item \textbf{Финальная модель — AST v2} — показала лучший результат по совокупности задач: среднее accuracy 58.5\%, в том числе segment 40.6\% (на 5.3 п.п. лучше CNN v2 baseline) и genre 81.5\% (на 2.4 п.п. ниже лучшего CNN v2).

  \item \textbf{Реализован композитный post-processing pipeline} (Viterbi-декодирование + musicological position priors + итеративное min-duration merge), повышающий Boundary F1 сегментной задачи на 14 пунктов и сокращающий число выдаваемых сегментов с 28 до 7.5 в среднем (близко к реальному числу музыкальных секций).

  \item \textbf{Разработан полнофункциональный веб-прототип} с трёхзвенной архитектурой (FastAPI ML inference + Elysia/Bun backend + React/Vite frontend) и кастомным фреймворком синхронизированного дашборда. Шесть аналитических панелей (структура, эмоциональный анализ, эмоциональная траектория Russell circumplex, жанр со stacked area, мел-спектрограмма, сводка) обеспечивают полноценную визуализацию результатов модели.

  \item \textbf{Идентифицированы и документированы ограничения} подхода: out-of-distribution на современной музыке, нижний предел сегментной точности, размер и латентность модели, отсутствие multi-label жанровой классификации. Для каждого ограничения предложены mitigation в текущей реализации и долгосрочные решения.
\end{enumerate}

\subsection*{Научная новизна и вклад}
\addcontentsline{toc}{subsection}{Научная новизна и вклад}

К научному вкладу работы следует отнести:

\begin{itemize}
  \item Первое известное автору систематическое сравнение пяти архитектур (включая трансформер) для мульти-задачного MIR на едином датасете DEAM+Harmonix+GTZAN.
  \item Композитный post-processing pipeline с количественной оценкой вклада каждого компонента — стандартизация практик пост-обработки в MIR.
  \item Документированный паттерн «академически честного UX» для классификации с ограниченным набором категорий — top-3 + confidence warning при OOD.
  \item Документированный negative result эксперимента CNN v3 — академически добросовестное сообщение о провале гипотезы aggressive reweighting.
\end{itemize}

\subsection*{Направления дальнейшей работы}
\addcontentsline{toc}{subsection}{Направления дальнейшей работы}

Прямые направления развития системы:

\begin{enumerate}
  \item \textbf{Дообучение жанровой головы} на современном датасете (FMA, MagnaTagATune) с поддержкой multi-label предсказаний — устранит OOD-проблему на современных жанрах.

  \item \textbf{Knowledge distillation AST → MobileViT} для уменьшения размера модели в 10–20 раз без существенной потери качества — откроет возможность mobile deployment.

  \item \textbf{Streaming inference} через скользящее окно — позволит обрабатывать треки произвольной длительности с фиксированной памятью.

  \item \textbf{Расширение датасета} через synthetic augmentation (генеративные модели музыки) или включение SALAMI/Beatles — повысит качество сегментной задачи за счёт большей вариативности обучающих примеров.

  \item \textbf{Real-time analysis} — оптимизация inference до $<$ 100\,мс на 10-секундное окно, что позволит интеграцию в live-приложения (DJ-инструменты, ритм-игры).
\end{enumerate}

Перспективные исследовательские направления:

\begin{enumerate}
  \setcounter{enumi}{5}
  \item \textbf{Joint training с генеративными задачами} — обучение модели одновременно на анализе и на reconstruction/generation; это может улучшить качество всех аналитических голов через общий backbone.

  \item \textbf{Self-supervised pretraining на музыкальных данных} — создание собственного «AudioSet для музыки» из неразмеченных стриминговых сервисов и pretraining модели на нём; избавит от зависимости от GTZAN/DEAM/Harmonix.

  \item \textbf{Cross-modal extension} — связывание аудио-анализа с текстом (lyrics analysis, mood description) и видео (music video shot detection) для построения полной multimodal-системы понимания музыки.
\end{enumerate}

\subsection*{Заключительное слово}
\addcontentsline{toc}{subsection}{Заключительное слово}

Музыкальный анализ остаётся одной из наиболее сложных областей машинного обучения из-за высокой субъективности аннотаций, разнообразия культурных контекстов и фундаментальной полисемии звука. Настоящая работа делает скромный, но систематический шаг в направлении универсальной мульти-задачной модели и интерактивного demonstrator-прототипа — площадки для дальнейших исследований и практических применений. Полученные результаты подтверждают применимость современных deep learning архитектур (особенно трансформеров с pretraining) к MIR-задачам, выявляют конкретные направления для последующего улучшения и предоставляют open-source инструментарий, готовый к использованию академическим и промышленным сообществом.

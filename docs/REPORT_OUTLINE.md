# Каркас отчёта магистерской НИР

## 1. Введение
- Актуальность анализа музыкальных композиций
- Цель и задачи работы
- Практическая значимость (ритм-игры, автоматическая разметка)

## 2. Обзор литературы
- Music Information Retrieval (MIR): основные направления
- Структурный анализ музыки (Music Structure Analysis)
- Распознавание эмоций в музыке (Music Emotion Recognition)
- CNN в задачах аудиоанализа
- Мультизадачное обучение (Multi-Task Learning)

## 3. Метод
- Общая архитектура системы
- Извлечение признаков (лог-мел спектрограмма, chroma, MFCC)
- Архитектура CNN (backbone + 3 головы)
- Мультизадачное обучение на разнородных датасетах
- Пост-обработка предсказаний в сегменты

## 4. Данные
- DEAM: описание, предобработка, дискретизация arousal/valence
- Harmonix/SALAMI: описание, маппинг меток в 4 класса
- Стратегия разбиения на train/val/test

## 5. Эксперименты
- Настройка обучения (гиперпараметры, оптимизатор, scheduler)
- Результаты: accuracy, macro-F1, confusion matrix
- Абляции: log-mel vs log-mel+chroma; single-task vs multi-task
- Анализ ошибок
- Качественные примеры (графики таймлайнов)

## 6. Заключение
- Основные результаты
- Ограничения
- Направления дальнейшей работы
